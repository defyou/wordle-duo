# Wordle Дуэт

Wordle на двоих: два игрока подключаются, выбирают режим («классический» —
угадывают слово вместе на одном поле, или «по очереди») и разгадывают одно
слово вдвоём, общаясь в чате.

Что было сделано, чтобы игра реально заработала (в исходном архиве был
только фронтенд без единого сервера):

- **`server/wsServer.mjs`** — WebSocket-сервер (протокол RFC6455) на голом
  Node.js, без единой внешней зависимости.
- **`server/game.mjs`** — вся игровая логика: подбор соперника, выбор слова,
  проверка догадки (с корректной обработкой повторяющихся букв, как в
  настоящем Wordle), режим "по очереди", чат, реванш, обработка отключений.
- **`server/words.mjs`** — словарь из 171 русского 5-буквенного слова
  (легко расширяется, см. ниже).
- **`server/main.mjs`** — единая точка входа: в разработке поднимает Vite
  в middleware-режиме (HMR), в проде отдаёт собранную статику. WebSocket и
  HTTP работают на одном порту.
- **`src/lib/socket.ts`** — клиент заменён с `socket.io-client` на нативный
  браузерный `WebSocket` (без зависимостей), с привычным `on/off/emit` API.
- Приведён в порядок `package.json`/`tsconfig.json`/`vite.config.ts` — раньше
  они были частью Replit-монорепы (`catalog:`, `workspace:*`, ссылки на
  файлы за пределами архива), из-за чего `npm install` не сработал бы вне
  той монорепы.

## Важное ограничение

Я собираю и тестирую этот проект в песочнице без доступа в интернет, поэтому
**не могу сам залить его на внешний хостинг** — ни `npm install`, ни выход в
сеть отсюда не работают. Зато я прогнал всю игровую логику и сам
WebSocket-протокол через собственный тестовый сценарий прямо здесь (два
клиента, полный цикл игры, оба режима, чат, дисконнект) — всё проходит:

```
npm run selfcheck
```

Ниже — что нужно сделать у себя, это буквально несколько команд.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте `http://localhost:5000` в двух вкладках (или на двух устройствах) —
это и есть игра на двоих.

## Продакшн-сборка

```bash
npm install
npm run build
npm start
```

`npm start` поднимает тот же сервер в режиме production и отдаёт собранный
клиент из `dist/public`. Порт берётся из переменной окружения `PORT`
(по умолчанию 5000).

## Деплой на реальный сервер

Проще всего — любой хостинг, который умеет "Node.js web service":

### Render.com / Railway.app (бесплатный тариф есть у обоих)
1. Залейте эту папку в свой GitHub-репозиторий.
2. Создайте новый Web Service, подключите репозиторий.
3. Build command: `npm install && npm run build`
4. Start command: `npm start`
5. Готово — платформа сама пробросит `PORT` и выдаст публичный URL.

### Свой VPS (Ubuntu и т.п.)
```bash
git clone <ваш репозиторий>
cd wordle-duo
npm install
npm run build
PORT=3000 npm start
# для постоянной работы — pm2 или systemd:
npx pm2 start server/main.mjs --name wordle-duo --env production
```
Дальше поставьте nginx как reverse proxy на 80/443 (не забудьте настроить
проксирование WebSocket-заголовков `Upgrade`/`Connection`).

## Как расширить словарь

Слова лежат в `server/words.mjs` — это простой массив строк в верхнем
регистре, каждое ровно из 5 кириллических букв (без "Ё" — она на клавиатуре
в игре преобразуется в "Е"). Просто добавьте туда новые слова.
